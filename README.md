# EMD Garage

نظام سحابي لإدارة الكراجات يُباع باشتراك: الاستلام، لوحة الورشة، أوامر العمل، المخزون، الفواتير الضريبية والدفعات، ورسائل واتساب.

- واجهة ويب تقدمية (PWA) بلا خطوة بناء: HTML وCSS وJavaScript modules.
- قاعدة البيانات والمصادقة: Supabase (مشروع `garage-pro`)، وكل الصلاحيات وعزل بيانات الكراجات مفروضة في قاعدة البيانات (RLS).
- النشر: GitHub Pages من فرع `main`.

## التشغيل محلياً
```
python3 -m http.server 8080
```
ثم افتح http://localhost:8080

## الوحدات المنشورة
- المرحلة 1: الاستلام، لوحة الورشة، أوامر العمل، الفواتير والدفعات، العملاء، المخزون، الإعدادات والفريق والدعوات.
- المرحلة 2: المواعيد وتذكير الصيانة، الموردون والمشتريات (متوسط التكلفة)، المصروفات، كارت الصنف، التقارير، التسعير ونسبة التشغيل، المحاسبة بالقيد المزدوج (الميزانية، قائمة الدخل، ميزان المراجعة، القيود، دليل الحسابات، دفتر الأستاذ، كشوف حساب العملاء والموردين).

## قاعدة البيانات
كل الحسابات والصلاحيات والقيود المحاسبية تتم داخل Supabase (دوال PostgreSQL + RLS)، والواجهة لا تحسب أي رقم مالي نهائي بنفسها.
